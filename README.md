# 하리나 매치룸

스타크래프트 CK, PL, 랜능크, 빨무 대진을 한 화면에서 관리하는 웹앱입니다.

## 주요 기능

- 팀과 선수(이름, 티어, 본종) 등록
- 갓·킹·잭·조커·스페이드·0~8티어·유스 드롭다운 선택
- CK·PL 경기별 부종 선택
- 부종리그 및 선수별 부종 사전 등록
- 위너스 방식: 승자 자동 잔류, 패자 탈락 및 다음 선수 교체
- 위너스 종료 조건: 한 팀 전원 탈락 또는 지정 경기 수
- 운영자가 필요할 때 에이스 결정전 직접 추가·삭제
- 랜능크·빨무 기본 랜덤 및 저티어 지정 종족 선택
- 세트 추가 및 세트별 1·3·5·7·9·11경기 설정
- 맵과 세트별 대진 순서 입력
- 경기 승패, 세트 다승팀 및 전체 세트 스코어 자동 계산
- PC 한 화면 활용을 위한 기본 밀집형 레이아웃 및 전체화면 버튼
- 브라우저 자동 저장
- JSON 백업 및 복원
- 새 버전 배포 시 실행 중인 화면에서 자동 감지 및 새로고침

## 업데이트 방식

`main` 브랜치의 파일이 변경되면 GitHub Pages에 자동으로 배포됩니다. 페이지를 열어둔 사용자는 1분 간격으로 새 버전을 확인하며, 새 버전이 확인되면 자동으로 새로고침됩니다. 사용자 입력 데이터는 브라우저에 별도로 저장되어 업데이트 후에도 유지됩니다.
